# Final repository release

The frozen experimental reference is `FINAL_PROJECT_REPORT.md`. This packaging
release does not change pipeline code, experimental results or existing manifests.

Git includes the source, tests, research scripts, reports, configuration, pinned
dependencies, evidence manifests, metrics, predictions and the reasonably sized
final contribution model bundles. Earlier notebook outputs remain explicitly
historical; README identifies the final evidence.

Intentionally local and ignored:

- `.venv`, Python/editor caches, credentials and temporary files;
- raw CHB-MIT data and `data/processed/corrected_v2/`;
- older validation bundles under `results/corrected/**/bundles/`;
- three approximately 264 MB SR/SRCR extended feature tables;
- two approximately 84 MB PSD-ablation replacement feature tables.

These files are not deleted or regenerated by the release. Their existing
manifests and reproduction instructions remain versioned. A clone is a source
and evidence release, not a complete raw/derived dataset distribution. Validators
requiring intentionally omitted artifacts need the preserved local artifact set
or reproduction into separately named locations. Preserve that local set for the
FYP archive; Git history alone is not its backup.

The final annotated tag records the frozen release commit. `main` is the final
development branch; ancestor branches may be removed only after publication and
reachability checks. The `teammate` remote is an external reference repository;
its branches are outside this release's pruning scope.

Historical manifests also fingerprint documentation and source inventories from
their creation time. The intentional README revision is archived at
`results/final/README-before-final-release-v1.md`; this release additionally
changes only repository packaging files. Existing experimental manifests are
preserved rather than rewritten to disguise these documentation changes.
